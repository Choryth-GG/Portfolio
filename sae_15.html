SAE 1.5

Exploitation de données via une API

Présentation du projet

L’objectif de cette SAE était d’utiliser les données fournies par une API afin de récupérer différentes informations sur un type de lieux.

Pour ce projet, nous avons utilisé l’API OpenStreetMap. Nous devions extraire des données comme le nom des lieux ou leurs horaires d’ouverture, puis transformer ces informations en format Markdown afin de les afficher sous forme de texte sur un site internet.

Ce projet m’a permis de découvrir le fonctionnement des API et la manipulation de données.

Compétences évaluées

AC13.01 – Utiliser un système informatique et ses outils

Utilisation d’un environnement de développement avec éditeur de code et navigateur pour tester l’API.

AC13.02 – Lire, exécuter, corriger et modifier un programme

Lecture et modification de programmes pour corriger des erreurs.

AC13.03 – Traduire un algorithme

Mise en place d’un algorithme pour récupérer et convertir les données en Markdown.

AC13.04 – Architecture web

Compréhension de l’intégration de données externes via API.

AC13.05 – Gestion de données

Choix du Markdown pour un affichage clair.

AC13.06 – Travail collaboratif

Travail en groupe et partage du code.

Compétences acquises

  • Compréhension du fonctionnement d’une API
  • Récupération et traitement de données externes
  • Conversion de données pour l’affichage
  • Lien entre données et site web
  • Travail collaboratif

Compétences à améliorer

  • Approfondir le filtrage de données d’API
  • Gagner en autonomie algorithmique
  • Mieux organiser le code

Analyse et conclusion

Cette SAE m’a permis de comprendre comment exploiter des données externes via une API et de les transformer pour un affichage web. J’ai appris à manipuler les informations, à les organiser et à présenter un contenu clair et lisible sur un site.

Ce projet m’a également permis de développer mes compétences en travail collaboratif et en gestion de projet, tout en approfondissant ma compréhension des technologies web.
