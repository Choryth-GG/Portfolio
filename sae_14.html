SAE - Création de site web

Projet HTML & CSS

Compétences évaluées

  • ✔ Structurer une page web en HTML
  • ✔ Mettre en forme un site avec CSS
  • ✔ Organiser le contenu d’un site web
  • ✔ Comprendre la structure d’un site internet

Présentation du projet

Le but de cette SAE était de réaliser un site internet simple en utilisant uniquement le HTML et le CSS.

Ce projet m’a permis de mettre en pratique les notions vues en cours et de mieux comprendre comment est structuré un site web.

J’ai appris à créer des pages, organiser le contenu et appliquer une mise en forme basique.

Travail réalisé

Durant cette SAE, j’ai conçu plusieurs pages web en utilisant les balises HTML principales. J’ai également appliqué des styles CSS pour améliorer l’apparence du site.

Le travail comprenait l’organisation du contenu, la création de liens entre les pages et la mise en place d’une structure claire et lisible.

Analyse et conclusion

Cette SAE a été une bonne introduction au développement web. Elle m’a permis de mieux comprendre le fonctionnement du HTML et du CSS.

Ce projet m’a donné des bases solides pour créer des sites plus complexes à l’avenir et m’a permis de gagner en autonomie.
