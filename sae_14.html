SAE - Création de site web

Projet HTML & CSS

Compétences évaluées

  • Structurer une page web en HTML
  • Mettre en forme un site avec CSS
  • Organiser le contenu d’un site web
  • Comprendre la structure d’un site internet

Présentation du projet

Le but de cette SAE était de concevoir et de réaliser un site internet simple en utilisant uniquement les langages HTML et CSS, tout en respectant les normes du W3C et les bonnes pratiques de développement web. L’objectif n’était pas seulement d’obtenir un site fonctionnel, mais aussi de produire un code propre, lisible et bien structuré afin de faciliter sa compréhension et sa maintenance.

Ce projet m’a permis de mettre en pratique les notions vues en cours et de mieux comprendre comment est structuré un site web.

Travail réalisé

Durant cette SAE, j’ai conçu plusieurs pages web en utilisant les balises HTML principales et du CSS pour le style.

Le travail comprenait l’organisation du contenu, les liens entre pages et une structure claire. Le site devait être facile à naviguer et agréable visuellement. Il devait aussi être responsive, c’est-à-dire s’adapter à différentes tailles d’écran.

Compétences évaluées

AC13.01 – Utiliser un système informatique et ses outils

Utilisation d’un environnement de développement avec éditeur de code et éditer et tester les pages web.

AC13.04 – Connaître l’architecture et les technologies d’un site Web

Compréhension de la structure d’un site web et des technologies utilisées (HTML, CSS).

Analyse et conclusion

Ce projet m’a permis de mettre en pratique les notions abordées en cours, notamment la structuration d’une page web, la séparation du contenu et de la mise en forme, ainsi que l’organisation des fichiers d’un projet web. J’ai ainsi pu mieux comprendre comment se construit un site internet, de la création des pages à leur affichage dans un navigateur.

Au cours de cette SAE, j’ai appris à réfléchir à l’organisation du contenu avant même de coder, à hiérarchiser les informations (titres, paragraphes, images, liens) et à proposer une présentation claire pour l’utilisateur. J’ai également découvert l’importance d’adapter l’affichage du site aux différentes tailles d’écran, notamment grâce aux bases du responsive design, afin de rendre le site consultable aussi bien sur ordinateur que sur mobile.
