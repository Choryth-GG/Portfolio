SAE - Création de site web

Projet HTML & CSS

Compétences évaluées

  • Structurer une page web en HTML
  • Mettre en forme un site avec CSS
  • Organiser le contenu d’un site web
  • Comprendre la structure d’un site internet

Présentation du projet

Le but de cette SAE était de réaliser un site internet simple en utilisant uniquement le HTML et le CSS.

Ce projet m’a permis de mettre en pratique les notions vues en cours et de mieux comprendre comment est structuré un site web.

J’ai appris à créer des pages, organiser le contenu et appliquer une mise en forme basique.

Travail réalisé

Durant cette SAE, j’ai conçu plusieurs pages web en utilisant les balises HTML principales et du CSS pour le style.

Le travail comprenait l’organisation du contenu, les liens entre pages et une structure claire.

Analyse et conclusion

Cette SAE a été une bonne introduction au développement web et m’a permis d’acquérir des bases solides.

Elle me servira pour créer des sites plus complexes à l’avenir.
